# Glossari de Vocabulari Tècnic

Aquest fitxer conté el recull de conceptes tècnics clau utilitzats durant el desenvolupament del projecte.

---

### Backlog
- Anglès: Product Backlog
- Definició: Llista ordenada amb totes les tasques i feines pendents que s'han de fer en un projecte.
- Exemple: Vam afegir la tasca de creació de la base de dades al Backlog del projecte.

### Branch (Branca)
- Anglès: Branch
- Definició: Espai separat del codi principal per provar o afegir coses noves sense fer malbé el que ja funciona.
- Exemple: Vaig crear la branca feature-login per programar el formulari d'accés sense trencar la versió principal.

### Clone (Clon)
- Anglès: Clone
- Definició: Descarregar una còpia sencera d'un projecte de GitHub a l'ordinador per poder treballar-hi.
- Exemple: Vaig fer un clone del repositori de l'institut per tenir els fitxers de la pràctica al meu ordinador.

### Commit
- Anglès: Commit
- Definició: Guardar i registrar els últims canvis que has fet als teus fitxers locals, com si fos una foto del moment.
- Exemple: Després de corregir els errors del codi, vaig fer un commit amb el messatge "Fix: resolt bug de validació".

### Commit Message
- Anglès: Commit message
- Definició: Text curt que escrius en fer un commit per explicar quins canvis has fet.
- Exemple: Recorda utilitzar un commit message clar perquè els companys entenguin el teu codi.

### Daily Scrum
- Anglès: Daily Scrum / Daily Stand-up
- Definició: Reunió diària molt curta de l'equip per dir què has fet, què faràs i si estàs encallat en alguna cosa.
- Exemple: A la Daily d'aquest matí hem comentat que teníem problemes de connexió amb el servidor.

### Fork
- Anglès: Fork
- Definició: Còpia d'un projecte d'una altra persona que et guardes al teu compte de GitHub per modificar-lo lliurement.
- Exemple: Vam afegir un exemple de fork agafant el projecte del professor per poder començar a treballar.

### Issue
- Anglès: Issue
- Definició: Targeta o tiquet digital a GitHub que serveix per apuntar una tasca a fer, una idea o un error a solucionar.
- Exemple: He obert una issue a GitHub perquè el botó de tancament de sessió no funciona correctament.

### Milestone (Hita)
- Anglès: Milestone
- Definició: Objectiu de grup a GitHub que uneix diverses tasques i serveix per controlar el progrés abans d'una data límit.
- Exemple: Vam associar totes les tasques de disseny a la Milestone de la "Fase 1".

### Project Board (Tauler de Projecte)
- Anglès: Project board
- Definició: Tauler visual a GitHub dividit en columnes per veure ràpidament l'estat de totes les tasques.
- Exemple: Vam moure la targeta de la tasca a la columna de "In progress" dins del Project Board.

### Pull Request (PR)
- Anglès: Pull Request
- Definició: Petició formal que fas a GitHub per demanar als companys que revisin el teu codi i l'ajuntin al projecte principal.
- Exemple: Vaig obrir una Pull Request per integrar les meves millores al repositori del grup de treball.

### Push
- Anglès: Push
- Definició: Enviar o pujar els canvis i commits fets al teu ordinador cap al servidor remot de GitHub.
- Exemple: Un cop fets els commits locals, vaig fer un push per compartir el codi amb l'equip.

### Repository (Repositori)
- Anglès: Repository
- Definició: Carpeta digital a GitHub on es guarden tots els fitxers d'un projecte i l'historial del que s'ha anat modificant.
- Exemple: El professor ha creat el repositori oficial de l'assignatura per lliurar les pràctiques.

### Sprint
- Anglès: Sprint
- Definició: Període curt de temps (normalment de 1 a 3 setmanes) on l'equip es concentra a acabar unes tasques fixes.
- Exemple: En aquest primer Sprint de dues setmanes hem de programar la interfície gràfica de l'aplicació.

### Status (Estats d'una tasca)
- Anglès: Status
- Definició: Indicador que diu exactament en quin punt es troba una tasca (com per exemple: pendent, en procés o acabada).
- Exemple: El valor de l'Status d'aquesta issue s'ha actualitzat automàticament a "Done" en fusionar el codi.
